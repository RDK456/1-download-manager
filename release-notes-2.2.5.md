## What's new

**Browser extension**
- Catches downloads from any site. Before, links from sites outside a short built-in list were refused and left to the browser.
- Holds the browser's own copy the moment a download starts, so small files are no longer saved twice or missed. If the app is closed, the browser carries on as usual.
- Asks for fewer permissions (removed the unused `scripting` and `activeTab`).

**Windows**
- "Start minimized" now starts hidden in the system tray, with no taskbar button.
- Large cookie sets from signed-in sites no longer make a capture fail.

**Android**
- New Quick Settings tile, "Download copied link": copy a link anywhere, tap the tile, and it opens ready to add.
- Smaller download (about 12 MB less) from release shrinking.
