## Desktop
- Paste a link or several links (one per line) with Ctrl+V and the add window opens already filled.
- fuckingfast.co links are resolved to the real file, so the name, type and size are right and the download works.
- Several links sent from the browser open the Link grabber with a "Save all in a folder" box, named after what the files share (for example `CoD_MW4`), and a total size.
- Browser Integration: Chrome and Firefox now install from their store pages.

## Browser extension
- Select a list of links on a page, right-click, and choose "Download selected links with 1DM" to send every one.
