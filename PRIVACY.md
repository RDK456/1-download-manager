# Privacy policy

Last updated: 2026-10-12

The "1 download manager" browser extension does not collect, store or sell personal data, and has no servers, analytics, ads or tracking.

## What the extension handles

When you start a download, click the Download key on a video, or use the right-click menu, the extension sends the link, the page address, the page's cookies for that site and the file name to the **1 download manager desktop app running on your own computer** (`127.0.0.1`, a local address). This is so the app can fetch the file with your login, exactly as your browser would.

The extension also remembers, in your browser's local storage, the app port, the pairing code, your settings and the list of sites you switched it off for. The list of media streams a page played is kept in memory for that tab only.

## What leaves your computer

Nothing is sent to the developer or to any third party by the extension. The only network traffic it creates is to the local app on your machine. The app then downloads the file from the site you were already on.

## Remote code

The extension does not load or run remote code. All its code is in the package.
